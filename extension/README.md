# Flexie Chrome/Edge Browser Extension

A Manifest V3 browser extension integrating Flexie directly into Google Chrome, Microsoft Edge, Brave, and other Chromium browsers.

## Capabilities

1. **Ask Flexie About This Page**: Summarize, extract takeaways, or answer questions with full page context.
2. **Floating "Ask Flexie" Pill**: Appears automatically upon text selection to explain, rewrite, or debug.
3. **Context Menus**: Right-click on any webpage, image, or code snippet to analyze with Flexie.
4. **Voice Dictation**: Built-in speech recognition in the sidebar for hands-free queries.
5. **Direct Backend Link**: Relays requests via authenticated REST API (`http://127.0.0.1:8768`).
6. **Permission Controls**: Interactive approval prompts before executing sensitive page actions or forms.

## Installation in Chrome / Edge

1. Open your browser and navigate to `chrome://extensions/` or `edge://extensions/`.
2. Toggle **Developer mode** (top right switch).
3. Click **Load unpacked**.
4. Select this directory:
   ```text
   e:\HACKATHON\flexiee\flexie_v2\extension
   ```
5. Pin the **Flexie** icon in your browser toolbar.
6. Click the icon and select **Open Flexie Sidebar**.
